The Raspberry Pi Compute Module 4 (CM4) is a powerful single-board computer developed by the Raspberry Pi Foundation. It delivers enhanced capabilities compared to previous models, providing a versatile platform for both hobbyist and professional applications.

| Feature       | Specification                                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Processor     | Broadcom BCM2711 quad-core Cortex-A72 (ARM v8) 64-bit SoC @ 1.5GHz                                                          |
| RAM           | LPDDR4-3200 SDRAM, available in 1GB, 2GB, 4GB, or 8GB variants                                                              |
| Storage       | Optional eMMC flash, available in 8GB, 16GB, or 32GB, or a microSD card slot                                                |
| Connectivity  | Optional 802.11b/g/n/ac wireless LAN and Bluetooth 5.0; Gigabit Ethernet available via IO Board                             |
| PCIe          | 1-lane PCI Express 2.0 interface                                                                                            |
| GPIO          | Standard 40-pin GPIO header, up to 28 GPIOs available                                                                       |
| Power Input   | VBAT (2.97V to 5.5V) and 5VSB (5V)                                                                                          |
| Video & Audio | 2 × HDMI 2.0 ports, 2-lane MIPI DSI display port, 2-lane MIPI CSI camera port, 4-pole stereo audio and composite video port |
